# Block writes while comments are unresolved

Any unresolved Google Docs comment will act as a Review Barrier that blocks every content-changing publish; no-op inspection remains allowed, and suggestions follow the normal paragraph/table conflict rules because their ranges are available in the stable Docs read model. The stable Drive API can list unresolved comments under the existing `drive.file` scope but cannot reliably map their anchors to current document ranges, while exact Docs comment ranges remain a Developer Preview feature. Version one has no force bypass for this barrier. Extending ADR 0008's browser-owned provisioning handoff, `pumd` will require both the Docs and Drive APIs to be enabled, using Drive only for comment inspection rather than publication discovery and without broadening OAuth scope. This chooses coarse safety over a risk of detaching review feedback.
